# AI Knowledge Base Assistant (RAG Chatbot)

This project implements a Retrieval-Augmented Generation (RAG) system that allows users to query documents using semantic search.

## Features
- PDF document ingestion
- Text chunking
- HuggingFace embeddings
- FAISS vector database
- Semantic retrieval

## Tech Stack
Python, LangChain, FAISS, HuggingFace, FastAPI
